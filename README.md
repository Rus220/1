# Telegram Customs Calculator Bot

Telegram-бот для расчёта стоимости растаможки автомобилей из Китая с доставкой в Казань.

## Функции

- Парсинг информации об автомобиле из пересланных сообщений
- Автоматическое получение курсов ЦБ РФ (EUR, CNY)
- Расчёт полной стоимости: инвойс, комиссия банка, пошлина, оформление, утильсбор, логистика, брокер
- Генерация готового поста для Telegram-канала

## Запуск

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="your-token-here"
python bot.py
```

## Тесты

```bash
pytest tests/ -v
```
